What it actually catches.

The mistakes that keep showing up in apps built fast with AI, plus the standards auditors ask about.

  • Leaked keysOpenAI, Stripe, AWS, GitHub and more, including secrets hidden behind NEXT_PUBLIC_ or VITE_
  • Open databasesSupabase tables without RLS, Firebase rules set to "if true", service keys in the app
  • InjectionSQL, NoSQL and shell commands built from user input, in every major language
  • Broken accessUsers reading each other's data, admin routes left open, mass assignment
  • AI-specific risksModel keys in the browser, model output being executed, over-powered agent tools
  • Cloud and CIRoot containers, public buckets, open ports, injectable GitHub Actions
  • MobileCleartext traffic, debuggable builds, tokens in plain storage
  • Missing basicsNo tests, no lockfile, no .gitignore, .env committed, no docs
