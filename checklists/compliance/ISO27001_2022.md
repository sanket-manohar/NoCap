# ISO/IEC 27001:2022 — Engineering Checklist

ISO 27001 certifies an **Information Security Management System (ISMS)**: clauses 4–10 (context, leadership, planning, support,
operation, performance evaluation, improvement) plus a **Statement of Applicability** over the **93 Annex A controls** in 4 themes.

## Annex A themes (2022)
- **A.5 Organisational (37)**: policies, roles, threat intelligence (5.7), information security for cloud services (5.23), ICT readiness for business continuity (5.30), supplier security, incident management
- **A.6 People (8)**: screening, awareness training, disciplinary process, remote working
- **A.7 Physical (14)**: secure areas, equipment, physical security monitoring (7.4)
- **A.8 Technological (34)**: endpoint devices, privileged access, secure authentication, malware protection, technical vulnerability management, configuration management (8.9), information deletion (8.10), data masking (8.11), data leakage prevention (8.12), backup, logging, monitoring activities (8.16), web filtering (8.23), cryptography, secure development lifecycle (8.25), application security requirements (8.26), secure architecture (8.27), **secure coding (8.28)**, security testing (8.29), outsourced development, separation of environments, change management
